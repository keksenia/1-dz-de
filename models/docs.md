# Витрины интернет-магазина

Loader копирует таблицы магазина из PostgreSQL в Greenplum (`dwh.raw`),
dbt готовит представления `analytics_staging`, объединяет данные в
`analytics_intermediate` и строит таблицы в `analytics_marts`

- `fct_orders` хранит заказы и итоги по платежам
- `fct_order_items` хранит позиции заказов для анализа продаж по товарам
- `dim_customers` включает всех зарегистрированных клиентов
- `dim_products` содержит товары, бренды и иерархию категорий
- `dim_dates` покрывает все даты заказов
- `fct_brand_returns` показывает долю возвратов по бренду и дате оформления заказа

Платежи и позиции агрегируются отдельно по заказу перед соединением,
для выручки по категориям используйте сумму `line_amount` по позициям
подтвержденных заказов, для среднего чека берите `order_amount` из факта заказов

Заказ 113 на 200 ₽ оплачен двумя успешными операциями по 200 ₽, тест
`assert_no_overpayment` сохраняет это нарушение как предупреждение
